# CasesBasis — Clinical Case Simulator

An AI-powered clinical simulation platform for trainee doctors. Generate realistic patient cases, interact with an AI patient, order investigations, and get evaluated on your clinical reasoning.

---

## Features

- **Case generation** — LLM generates a full clinical case from a diagnosis: patient demographics, persona, symptoms, vitals, progression timeline, risk factors, exam findings, and outcome. Supports easy / medium / hard difficulty.
- **Persona-based patients** — Every patient has an age, occupation, and communication style (e.g. "Stoic retired farmer, gives short answers, minimises pain"). The patient agent responds in character.
- **Restrained patient** — The patient only answers what was directly asked. Never volunteers extra symptoms. Exam findings (tachycardia, crepitations, etc.) are hidden — they must be discovered.
- **Voice I/O** — Speak your questions via browser mic; patient answers are read aloud with a gender-matched voice. Toggle TTS on/off.
- **Investigations** — Order any test by name. ECG returns a deterministic SVG waveform (ischemic or normal). All other tests (FBC, troponin, ABG, CXR, echo, cultures, etc.) are generated by the LLM with case-consistent numeric values, flags, and clinical hints.
- **Clinical knowledge graph** — Per-session FalkorDB graph extracts entities (symptoms, findings, medications, etc.) from each Q&A turn and investigation result in the background. Feeds context into the evaluator and doctor consult.
- **Senior doctor consult** — Request a consult at any time. Returns structured guidance without revealing the hidden diagnosis.
- **Evaluation** — Scored feedback covering symptom discovery, reasoning quality, investigation interpretation, and differential accuracy.
- **Multi-provider LLM** — Ollama (local, free), Groq, Together, OpenRouter, Cerebras, or OpenAI. Switch with one env var.

## Quick Start

### Prerequisites

- Python 3.11 (conda recommended)
- Docker (for the knowledge graph — optional, app works without it)
- Ollama or an API key for any supported provider

### Setup (conda)

```bash
make setup
# This creates the conda environment and starts FalkorDB in Docker

conda activate casesbasis
cp .env.example .env
# Edit .env — see configuration section below

uvicorn backend.main:app --reload --port 8000
```

Open [http://localhost:8000](http://localhost:8000).

### Setup (pip / venv)

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .[dev]
cp .env.example .env
uvicorn backend.main:app --reload --port 8000
```

## Running Fully Locally — No API Keys (Ollama)

```bash
# 1. Install and start Ollama
brew install ollama    # macOS; see https://ollama.com for other platforms
ollama serve

# 2. Pull a model
ollama pull qwen2.5:7b

# 3. Set .env
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434/v1
OLLAMA_MODEL=qwen2.5:7b

# 4. Run
uvicorn backend.main:app --reload --port 8000
```

FalkorDB (knowledge graph) is optional. If Docker isn't running, the graph is silently disabled and everything else works normally.

## Configuration

Set these in your `.env` file. All keys are optional except those for your chosen provider.

```env
# Provider — pick one
LLM_PROVIDER=ollama        # ollama | groq | together | openrouter | cerebras | openai

# Ollama (local, free)
OLLAMA_BASE_URL=http://localhost:11434/v1
OLLAMA_MODEL=qwen2.5:7b

# Groq
GROQ_API_KEY=gsk_...
GROQ_MODEL=llama-3.3-70b-versatile

# Together
TOGETHER_API_KEY=...
TOGETHER_MODEL=meta-llama/Llama-3.3-70B-Instruct-Turbo

# OpenRouter
OPENROUTER_API_KEY=sk-or-...
OPENROUTER_MODEL=nvidia/nemotron-3-super-120b-a12b:free

# Cerebras
CEREBRAS_API_KEY=...
CEREBRAS_MODEL=qwen-3-235b-a22b-instruct-2507

# OpenAI
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-2024-08-06

# FalkorDB (optional — knowledge graph)
FALKORDB_HOST=localhost
FALKORDB_PORT=6379

# LangSmith tracing (optional)
LANGCHAIN_TRACING_V2=true
LANGCHAIN_API_KEY=...
LANGCHAIN_PROJECT=casesbasis
```

## Project Structure

```
agents/          LLM agents (case generator, patient, investigations, doctor consult, evaluator)
backend/         FastAPI web app, services, ECG synthesizer, simulation runner
knowledge/       FalkorDB-backed per-session clinical knowledge graph
schemas/         Pydantic models for all data structures
tests/           pytest test suite
utils/           Shared utilities
docker-compose.yml   FalkorDB container
environment.yml      Conda environment spec
Makefile             Setup / start / stop shortcuts
claude_memory.md     Full implementation notes and handoff documentation
```

## Makefile Commands

```bash
make setup      # Create conda env + start FalkorDB (run once)
make start      # Start FalkorDB container
make stop       # Stop FalkorDB container
make restart    # Restart FalkorDB container
make logs       # Tail FalkorDB logs
make clean      # Remove conda env + Docker volumes (destructive)
```

## Self-Hosting

To expose the local app to the internet via Cloudflare Tunnel:

```bash
brew install cloudflare/cloudflare/cloudflared
cloudflared tunnel --url http://localhost:8000
```

This gives a public `*.trycloudflare.com` URL with no account required.
